# 🧩 Featured Project — FixItNow

## 🔧 FixItNow — Service Marketplace Platform

FixItNow is a web-based service marketplace platform that connects customers with technicians for home repair and maintenance services.

The platform allows:

* Customers to create service requests
* Technicians to browse and accept jobs
* Real-time chat between customers and technicians
* Ticket tracking and workflow management
* Authentication & role-based authorization

### ✨ Features

* 🔐 JWT Authentication & Authorization
* 👤 Customer & Technician Roles
* 📝 Ticket / Service Request Management
* 💬 Real-time Chat using SignalR
* 📦 Clean Architecture implementation
* 🗄 PostgreSQL Database
* 🎨 Responsive UI with MudBlazor
* ⚡ RESTful API with ASP.NET Core
* 🔄 State management and async data loading
