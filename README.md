## 🏢 Featured: KFM Online — Internal Performance Tracking System (Kalbe Farma Internship)

An internal web application used by Kalbe Farma to track and manage company-wide performance metrics. The system supports metrics setup, target approval workflows, results input/review, and dashboard reporting with audit trails.

**My contributions:** I worked across the full stack — building Blazor frontend components (filter-heavy dashboards, cascading dropdowns, server-side paging data grids, table/chart toggles with Excel export), implementing business service and data access layers with Entity Framework Core and PostgreSQL, and writing unit tests (NUnit, bUnit) for business and data services. I contributed to the Master Data, Metrics Setup, Metrics Results, Metrics Targets, and Dashboard Reporting modules.

**Architecture:** Layered CRUD with role-based access — Domain → Infrastructure (Data Service) → Application (Business Service) → Web (Blazor UI), with shared generic base classes for standard CRUD and audit-trail behavior. Highlights I worked on include role-scoped data access (users see only the business units/sites they're assigned to), custom year-range filtering beyond standard equality-based grid filters, and structured logging across the business service layer.

**Tech stack:** C# · ASP.NET Core · Blazor · Entity Framework Core · PostgreSQL · NUnit · bUnit · Layered Architecture

> 🔒 This is internal company software — the source code is confidential and not publicly shareable. Happy to walk through the architecture and design decisions in more detail during an interview or chat.
